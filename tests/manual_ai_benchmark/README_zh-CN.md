# JarvisArt 手工 AI 基准测试

> English: [README.md](README.md)

本目录包含一个可重复的**手工**基准测试流程，用于未来经过验证的本地 JarvisArt 安装。不要将私人照片、API Key、模型权重、由私人照片生成的预设或缓存模型响应提交到 Git。

## 运行前门槛

仅当以下所有条件成立时才运行本基准：

1. 模型来自官方 `JarvisArt/JarvisArt-1208` 页面。
2. 官方许可证仍随模型提供，且使用范围为非商业/非生产。
3. 本地设备拥有运行官方 BF16 checkpoint 及其视觉生成运行时所需的 GPU 显存，不依赖未经验证的社区量化版本。
4. 一张测试照片已明确授权用于本地基准测试。

## 固定对比

对同一张照片和同一条提示词，分别使用：

- Gemini（当前已配置的 Provider）
- Qwen（当前已配置的 Provider）
- JarvisArt（官方本地 checkpoint）

仅在本仓库外记录非敏感测量结果与可公开的结果产物：

| 维度 | 所需证据 |
| --- | --- |
| 输入路径 | 预览尺寸，以及确认云端测试没有上传原图 |
| 参数质量 | 已解析的 plan/preset、支持的操作和明确列出的不支持操作 |
| 渲染结果 | 相同源图、可视化前后导出结果，以及可用时的本地蒙版覆盖率 |
| 可靠性 | 请求/模型加载时长、解析成功/失败和错误类别 |
| 决策 | JarvisArt 是否在原生参数、Lightroom 原生渲染或专业工具规划任一方面更好 |

只有当 JarvisArt 在至少一项决策标准中胜出，且没有悄悄丢弃不支持的 Lightroom 操作时，才允许进行集成。

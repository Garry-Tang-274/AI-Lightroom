# 使用指南

[English](USER_GUIDE.md)

## 打开照片，找到要调的参数

点击空画布的**打开照片**，使用 **文件 → 打开图片**或 `Ctrl+O`，也可把 JPG / PNG 拖进画布。文件对话框支持多选，拖入多张照片同样会建立照片组。图片在后台载入，原始文件与可编辑预览分开保存。

画布标题旁的箭头或 `Alt+←` / `Alt+→` 用于切换组内照片；点击 `1 / 5` 这样的照片计数，可按文件名直接跳转。每张照片保留自己的编辑与撤回/重做历史：在当前组内回访已编辑照片时直接续接；首次打开有持久编辑记录的照片，仍会询问是否恢复。照片组用于导航，不是批量调色或批量导出命令。

右侧分为**调色**和 **AI 助手**两个标签页，上方显示直方图。在调色页展开分组，或按中英文名称搜索，例如 `曝光`、`Exposure`、`HSL`、`Grain`。清空搜索后恢复先前展开的分组。历史、蒙版和水印在左侧。

勾选**仅看已调整**，集中查看偏离默认值的参数。蓝色标签与分组计数标记已改项；HSL 颜色、曲线通道、分级区域名称旁的圆点表示该通道有调整。筛选可与搜索组合使用。计数统计全局控件，不包括蒙版和水印。

- 拖动滑块实时查看效果，松开后只生成一个撤销步骤。
- 拖动快速预览跟随**设置 → 性能与导出 → 性能模式**：默认平衡最长边为 1280 px，省电为 768 px，精细交互为 1600 px。松手恢复所选低清/高清质量；导出始终使用原图尺寸。
- 数值框可精确输入。点击旁边的复位图标或双击滑块恢复该参数默认值，几何缩放等非零默认值也会正确恢复；复位只产生一个撤销步骤。
- 滚轮只滚动面板，不会误改滑块、数值框和下拉选项。
- 曲线中点击加点、拖动调整、右键删除中间点；**重置**只重置当前通道。
- 色彩分级的阴影/中间调/高光控件下方，提供共用的**分级融合**和**分级平衡**。

直方图基于当前预览采样。高光百分比指任一 RGB 通道达到 255 的像素比例；黑位指三个通道都为 0 的比例，不代表 RAW 传感器裁切测量。

## 对比与专注查看

按住工具栏的**按住原图**，或按 `\` 切换原图。需要同时查看时，点击**左右对比**或按 `C`，再拖动画布中的分隔线：左边原图，右边当前调整。再次按 `C` 退出。

选择 **视图 → 专注模式**或按 `Ctrl+Tab` 隐藏两侧面板；再按一次恢复。`F` 适合窗口，`1` 按工作预览像素显示 100%；此处不是原始全分辨率检查模式。

## 局部蒙版

在左侧**蒙版**页选择类型，点击**添加**。选中图层后点**显示蒙版**，先用红色叠加检查选区，再调整局部曝光或色彩。

- **线性渐变**：可改起点/终点 X、Y。
- **径向渐变**：可改中心、水平/垂直半径、旋转及羽化。
- **明度范围**：可改明度上下限与羽化。
- **颜色范围**：可改目标色相、范围、最低饱和度与羽化。
- **画笔**：启用**在图片上绘制**，设置大小、硬度和不透明度后绘制；勾选**擦除笔触**清除已画区域。

坐标从 0 到 1，左上角为原点。蒙版可关闭、反转或删除。语义蒙版采用保守的图像分析，不是大型分割模型；先检查红色范围，识别不可靠时使用画笔或数学蒙版。

## 水印

左侧**水印**页可导入 PNG / JPG / WEBP 到本地水印库，并添加非破坏性图层。位置可选四角、居中或**自定义**；选择自定义后可改水平/垂直位置。大小、不透明度和边距均显示百分比，一次拖动只产生一次撤销。

**移除图层**只从当前照片移除。**从库删除**会在确认后删除储存的素材，不要仅为隐藏水印而使用；临时隐藏应取消**显示水印**。库中素材可重命名、设为默认，之后一键添加到其他照片。

## 复用与恢复编辑

### 将风格保存为配方

1. 调好一张照片，打开工具栏**配方**菜单，也可使用**编辑 → 调色配方**。
2. 选择**将当前调色存为配方…**并命名保存。替换同名配方前会询问确认。
3. 切到另一张照片，在**配方**中点击保存的名称。对应调色值会被替换，整个应用只产生一次撤销；参数已经一致时不制造空历史。

配方包含基础调色、HSL、曲线、分级、细节、效果和校准，保留目标照片原有的光学、几何、蒙版与水印。只保存参数，不保存照片像素，关闭程序后仍保留在本机应用设置中。**删除配方**只删除保存的配方，不改变已经应用到照片上的编辑。

### 临时复制，或恢复之前的编辑

**编辑 → 复制调整**（`Ctrl+Alt+C`）与**粘贴调整**（`Ctrl+Alt+V`）可复用全局明暗、HSL、曲线、分级、细节、效果、光学、几何和校准；默认不复制与特定照片有关的蒙版和水印。

`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；也可点击历史条目回到对应状态。应用设置中保存当前编辑、有限数量的历史条目及当前历史位置，不在原图旁生成文件。重新打开同一张未被外部修改的照片，选择**恢复编辑**即可继续，包括尚可重做的步骤；拒绝恢复则从原图开始。

## AI 调色

在 **文件 → 设置 → AI 服务**（`Ctrl+,`）配置 Provider。切到右侧 **AI 助手**页，输入期望效果，`Ctrl+Enter` 发送，`Enter` 换行。

请求期间显示实际阶段：检查配置、准备预览、等待本地/云端模型、校验与渲染，以及本次已用时间。这是实际工作状态，不是猜测的完成百分比；高清本地推理可能需要数分钟。期间禁止冲突编辑与重复发送。通过校验的整套方案作为一个撤回事务应用；失败时保留当前编辑。返回内容未改变任何参数时会明确提示；不支持的 JarvisArt 操作继续在调整详情中列出。

云端失败不会自动重试。只有需要再次调用时才点**重新尝试**。自动复检默认关闭，主动开启后可能增加一次请求。**取消等待**会提出取消并阻止结果应用，界面保留取消中状态，直到当前操作安全返回；它不能撤回已发送的云端请求，该次请求仍可能计数或计费，本地模型也可能继续运行已提交的任务。本地每日安全上限不代表服务商实时剩余额度。

**性能与导出**可让 AI 图像质量跟随画布或独立使用低清/高清；拖动期间临时的快速预览不会改变此设置。视觉调用发送受尺寸限制的 JPEG 预览，而非原始文件。JarvisArt Local GGUF 使用独立的 localhost 服务，Mock 模式禁止用于真实调色。部署与共用服务见 [JarvisArt 说明](JARVISART_zh-CN.md)。

## 另存全尺寸成片

用 `Ctrl+S` 或 `Ctrl+Shift+S`，选择 JPG / PNG，另存一个文件名。程序会拒绝覆盖当前照片组内的任何原图，不只保护屏幕上这一张。JPEG 质量可设，PNG 为无损。无论预览质量如何，导出都按原始尺寸重新应用当前参数、蒙版与水印。

导出先写临时文件，成功后替换所选输出，因此编码失败不会截断已有成片。**设置 → 性能与导出 → 导出 EXIF**中的**保留拍摄信息（可能含 GPS 位置）**默认开启。分享前可取消勾选，新导出的照片将去除摄影 EXIF，包括其中的 GPS；原始文件不变。有 ICC 的导入图像会转换为编辑器的 sRGB 工作色彩空间。

排障可用 **帮助 → 打开日志文件夹**，或在 AI 面板复制安全的错误详情。CPU 渲染性能改进的实测数据与条件见[配对性能测试](benchmarks/README.md)。

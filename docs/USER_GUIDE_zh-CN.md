# 使用指南

[English](USER_GUIDE.md)

使用 **文件 → 打开**、`Ctrl+O` 或拖入照片。中间画布使用可切换的工作预览；工具栏的 **低清预览 / 高清预览** 可以随时切换。自动模式下，云端 AI 默认低清，JarvisArt Local GGUF 默认高清。导出始终使用原始像素与当前非破坏性 `EditorState`。

右侧有基础参数、HSL、曲线、色彩分级、直方图与 AI。滑块在拖动中实时刷新，松开后只记录一条历史；滚轮不会误改滑块；双击可重置，数值框可精确输入。

在 **Masks** 中可创建渐变、范围、天空/主体/语义蒙版或画笔。显示蒙版会覆盖红色区域。每个蒙版都能开关、反相、羽化、调整、重命名和删除。**水印** 页保存用户素材并以非破坏性图层加入图片。

配置 Provider 后，`Ctrl+Enter` 发送 AI 指令，`Enter` 换行。AI 成功时会作为一个完整的撤回事务写入历史；失败时照片不改变。AI 发送图像质量可在设置中跟随画布或单独指定。JarvisArt Mock/Offline Mock 都不是真实视觉 AI，其中 JarvisArt Mock 已被阻止用于真实调色。
